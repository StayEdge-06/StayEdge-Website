The GBP shortlink resolves to a Google search-error page and does not surface in Google Maps at all. The Facebook page exists ("StayEdge | Tirupati") but has zero index footprint and isn't linked from anywhere. **Local SEO is a system: GBP → website → reviews → citations → rankings → trust.** When the website is half-parked, every profile in the system is a ghost. Fix the domain first; then GBP becomes StayEdge's single most valuable local asset — the Map Pack position that converts "Airbnb consultant Tirupati" searches into leads. Facebook's only real local value is in **Groups**, not the Page.
